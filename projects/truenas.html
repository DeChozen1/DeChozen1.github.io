TrueNAS Virtual NAS

Self-hosted storage project for learning local storage, ZFS and backups.

TrueNAS ZFS NAS Backups

Overview

TrueNAS is being developed as the storage layer of the homelab, with the longer-term aim of reducing reliance on cloud storage subscriptions. The project is also a practical exercise in virtualised storage, networking and backup design.

Documentation

TrueNAS Virtual Machine Installation Issue

During the initial TrueNAS installation, the virtual machine encountered multiple boot and console issues before the operating system could be installed successfully.

The first issue occurred when attempting to boot the TrueNAS installation media. The VM reported a UEFI Access Denied error when attempting to boot from the TrueNAS DVD.

UEFI and Secure Boot Investigation

The VM's UEFI configuration was investigated to determine whether Secure Boot or the EFI configuration was preventing the TrueNAS installer from starting correctly.

Changing the UEFI configuration alone did not resolve the boot problem, so the EFI configuration was investigated further, including recreating the EFI disk before continuing with the installation attempt.

Installer Console Failure

After getting past the initial boot issue and selecting the Install TrueNAS option, the installer console became unusable. The display showed a corrupted-looking output with vertical coloured lines and the installation appeared to stop progressing.

This shifted the investigation away from the original UEFI boot problem and towards the VM's virtual display and console configuration.

Troubleshooting Process

  • Investigated the UEFI boot failure and Access Denied message.
  • Checked the VM's Secure Boot and EFI configuration.
  • Tested the TrueNAS installation media again after modifying the VM's EFI configuration.
  • Selected the Install TrueNAS option and investigated the resulting corrupted console output.
  • Checked the Proxmox VM console and display configuration.
  • Investigated changing the VM display from Default to a Serial terminal for troubleshooting.
  • Restarted the VM and repeated the installation process while isolating the boot, display and console variables.

Current Status — 25 September 2026

The TrueNAS VM was removed after the installation issues. The storage project is now exploring Nextcloud as a private, self-hosted alternative for accessing personal files and large action-camera videos from an iPhone.

Nextcloud Appliance Setup

  • Imported the Nextcloud AIO virtual appliance into a new Proxmox VM.
  • Corrected the appliance's network interface configuration and confirmed that its web setup page loads.
  • Completed the initial setup steps and reached the domain configuration stage.
  • The appliance's built-in free domain registration was unavailable, so domain and HTTPS options are still being considered.

Access and Storage Plan

The intended access method is through the existing private VPN rather than exposing the file service directly to the public internet. A regular Docker deployment is being considered as an alternative to the AIO appliance, but no switch has been made.

The existing 4TB media drive has not been reformatted or integrated into Nextcloud. Its current files must be preserved while a suitable storage approach is planned.

Next step: Decide whether to continue with Nextcloud AIO or use a regular Docker deployment, then plan secure access and storage.

What This Demonstrates

  • Troubleshooting virtual machine boot failures at the UEFI level.
  • Understanding the relationship between Secure Boot, EFI configuration and virtualised operating-system installation.
  • Separating boot problems from operating-system installer problems.
  • Investigating virtual display and console configuration when an installer becomes visually corrupted or unresponsive.
  • Using controlled configuration changes to isolate the cause of a virtualisation problem.
