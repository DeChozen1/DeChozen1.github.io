10Gb Home Network

A real multi-gig home network built around a ViewQwest 10Gbps plan.

10GbE ViewQwest 10Gbps ASUS BE7200X AiMesh

Overview

This project documents the physical and wireless network surrounding the homelab. The environment is built around a ViewQwest 10Gbps connection, a primary ASUS BE7200X router and a second ASUS BE7200X connected through AiMesh to extend coverage into the office area.

The flat also includes built-in Ethernet ports in multiple rooms, with the room runs terminating at the central patch panel in the network cabinet. This allows the network to use high-speed wired backhaul throughout the home rather than depending solely on Wi-Fi.

The network also provides connectivity for the homelab, Home Assistant devices, personal systems and other IoT equipment. OPNsense is being introduced as the firewall and routing layer, with its own project page covering that implementation in more detail.

WireGuard Remote Access

A WireGuard VPN server has been configured on the primary ASUS router to provide secure remote access to the private home network. A dedicated client profile was created for a mobile device and imported using the router's QR-based setup process.

The connection was tested successfully over mobile data, allowing the device to reach selected services on the home network while away from home. The VPN is intentionally user-initiated rather than permanently enabled, so remote access is only established when it is needed.

The public documentation does not include internal IP addresses, public endpoints, usernames, private keys, QR codes or other sensitive VPN configuration. Only the architecture and outcome of the implementation are documented here.

ASUS AiMesh Setup

The wireless network uses two ASUS BE7200X routers. The primary router provides the main Home network, while a second ASUS BE7200X is connected through ASUS AiMesh and provides coverage for the Office side of the environment.

Using the same router model across both locations keeps the wireless environment within a single ASUS ecosystem while allowing the second unit to extend coverage without requiring a separate wireless platform.

Structured Cabling

One of the advantages of the flat is the built-in Ethernet cabling, with network ports available in multiple rooms and the room runs terminating at the central patch panel in the network cabinet.

This provides a wired backhaul between the cabinet and the rooms rather than relying entirely on Wi-Fi. The installed cabling and network path are capable of supporting multi-gigabit connectivity, with the longer-term goal of making 10GbE available to suitable wired devices where the connected hardware supports it.

This gives the network a combination of high-speed wired connectivity and Wi-Fi coverage, allowing bandwidth-intensive systems such as the homelab, desktops and other fixed devices to use Ethernet while mobile and IoT devices remain on the wireless network.

Network Layout

The network combines the high-speed wired homelab infrastructure with the wireless network used by everyday devices. The ASUS BE7200X units provide the main wireless access layer, while the Dell T5810 and its networking hardware form the core homelab infrastructure.

The Proxmox, OPNsense and TrueNAS projects document the individual components in greater detail; this project focuses on how those components fit into the wider home network.

Future Network Segmentation

One area being explored is the integration of an older Eero Max 7 into the environment. Several options are being considered, including using it as a separate network or investigating whether a bridged or extended configuration would make sense within the existing topology.

No final decision has been made yet. The objective is to determine whether the additional hardware can provide a useful role without unnecessarily complicating the network.

Security Lab

Another possible future development is a deliberately separated network for ethical hacking and security experimentation. The idea is to keep test systems and potentially vulnerable lab machines isolated from the main household environment while still allowing controlled access when required.

This would provide a dedicated environment for security learning, network testing and experimentation without mixing those systems directly with everyday personal and smart-home devices.

Relationship to the OPNsense Project

OPNsense is being introduced as the firewall and routing layer of the network, but the detailed passthrough and firewall configuration is documented separately in the OPNsense project. This page focuses on the wider physical network, wired infrastructure, wireless coverage and future network design.

Current Status

The 10Gb internet connection, core home network and AiMesh setup are in place. The built-in room Ethernet infrastructure also provides a wired alternative to Wi-Fi for fixed devices throughout the flat.

WireGuard remote access is now operational and has been verified from outside the home network. The OPNsense routing architecture is still being prepared for physical testing. Future work will also focus on deciding how the Eero Max 7 should be used and whether a separate security testing network should be introduced into the overall topology.

Lessons Learned So Far

  • A high-speed home network benefits from combining wired infrastructure with wireless coverage rather than relying on Wi-Fi alone.
  • A central patch panel makes it easier to manage and expand wired connectivity between the network cabinet and individual rooms.
  • Using matching wireless hardware simplifies extending coverage across different areas of the home.
  • Secure remote access is useful for a homelab, but exposing configuration details publicly is unnecessary and should be avoided.
  • Network segmentation needs to balance security, performance and operational complexity.
  • Additional hardware can be repurposed for dedicated environments as the network evolves.
