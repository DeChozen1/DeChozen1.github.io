10Gb Home Network

A real multi-gig home network built around a ViewQwest 10Gbps plan.

10GbEViewQwest 10GbpsOPNsenseASUS BE7200X

Overview

The current path is ViewQwest ONR/ONT in passthrough to a 10Gb NIC on the Dell T5810, where OPNsense is virtualised on Proxmox. OPNsense then routes to the ASUS BE7200X main router over 10GbE. The router also serves the Home Assistant backup Raspberry Pi and the Proxmox management connection from the T5810 onboard NIC.
