Local-First Home Assistant Platform

Home Assistant is one of the main workloads in the homelab and is designed around local control of smart-home devices rather than relying on a single cloud ecosystem. The setup combines Zigbee, network-based devices, ESP32 projects and automation through a central Home Assistant interface.

Home Assistant Virtualisation

The primary Home Assistant instance is being developed within the Proxmox environment on the Dell T5810, while a Raspberry Pi installation is retained as a backup environment. This provides a practical recovery path while the virtualised installation is being developed and tested.

Device Integration

  • Zigbee devices integrated through Home Assistant using ZHA.
  • Sonoff Zigbee coordinator used for local Zigbee communication.
  • ESP32-based devices integrated into the Home Assistant environment.
  • Network-connected smart-home devices tested across the changing homelab network.
  • Reolink cameras and other IoT devices reconnected after network changes.

Real Troubleshooting

The project has involved resolving real integration and connectivity problems, including Zigbee devices failing to re-pair, reconnecting ESP32 devices after network changes, restoring camera connectivity and maintaining a usable backup Home Assistant environment.

Primary and Backup Environment

The Proxmox-hosted Home Assistant instance is being developed as the primary environment, while the Raspberry Pi installation provides a contingency option. This allows the smart-home environment to remain recoverable while changes are being made to the main virtualised system.

Current Status

The Home Assistant environment is actively being developed as part of the wider homelab. Current work focuses on improving reliability, device integration, dashboards and the separation between the primary virtualised instance and the backup Raspberry Pi installation.

Lessons Learned So Far

  • Local-first smart-home systems can bring devices from different manufacturers into a single platform.
  • Network changes can affect multiple IoT integrations, making systematic troubleshooting important.
  • Maintaining a backup Home Assistant environment provides a recovery path while the primary system is being changed.
  • Smart-home reliability depends on both the application layer and the underlying network infrastructure.
