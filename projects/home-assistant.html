Local-First Home Assistant Platform

Home Assistant is one of the main workloads in the homelab and is designed around local control of smart-home devices rather than relying on a single cloud ecosystem. The setup combines Zigbee, network-based devices, ESP32 projects and automation through a central Home Assistant interface.

Home Assistant Virtualisation

The primary Home Assistant instance is being moved into the Proxmox environment on the Dell T5810, while a Raspberry Pi installation is retained as a backup environment. This provides a practical recovery path while the virtualised installation is being developed and tested.

Device Integration

  • Zigbee devices integrated through Home Assistant using ZHA.
  • Sonoff Zigbee coordinator used for local Zigbee communication.
  • ESP32-based devices integrated into the Home Assistant environment.
  • Network-connected smart-home devices tested across the changing homelab network.
  • Reolink cameras and other IoT devices reconnected after network changes.

Real Troubleshooting

The project has also involved resolving real integration problems, including Zigbee devices failing to re-pair, reconnecting ESP32 devices after network changes, restoring camera connectivity and maintaining a usable backup Home Assistant environment.

Current Status

The Home Assistant environment is actively being developed as part of the wider homelab. The focus is currently on improving reliability, device integration, dashboards and the separation between the primary virtualised instance and the backup Raspberry Pi installation.
