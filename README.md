# DeChozen1 Portfolio

Project-first personal portfolio for Siraj Hundal.

## Deploy to GitHub Pages
1. Upload the contents of this folder to `DeChozen1/DeChozen1.github.io`.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Wait for GitHub Pages to publish the site.

## Structure
- `index.html` — homepage
- `styles.css` — homepage styling
- `script.js` — project filters
- `projects/` — individual project pages
- `assets/homelab-cabinet-organized.png` — organised visual representation of the physical cabinet
- `assets/resume.pdf` — resume copy

## Notes
The cabinet image is labelled on the website as an organised representation rather than a documentary photograph. External client work is kept separate from the home lab portfolio and contains no confidential employer/client information.
